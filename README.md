# 两个一百年 · 鱼骨图

邓小平提出的"两个一百年"奋斗目标全景解读鱼骨图网页。

## 在线浏览

👉 **[foyfan.github.io/two-centenary-goals](https://foyfan.github.io/two-centenary-goals/)**

## 内容概要

| 鱼骨分支 | 主题 | 说明 |
|---------|------|------|
| 骨 ① | 邓小平"三步走"战略 | 1987年提出的现代化建设三步走部署 |
| 骨 ② | 第一个百年目标 (2021) | 全面建成小康社会 |
| 骨 ③ | 第二个百年目标 (2049) | 全面建成社会主义现代化强国 |
| 骨 ④ | 两阶段战略安排 | 2020-2035 / 2035-2049 |
| 骨 ⑤ | 核心内涵 | 共同富裕与民族复兴 |
| 骨 ⑥ | 历史意义 | 从邓小平到新时代的接续奋斗 |

## 技术栈

- 纯 HTML + CSS + JavaScript
- SVG 鱼骨图（Ishikawa Diagram）
- 响应式设计，支持明暗双主题
- GitHub Pages 部署

## 数据来源

- 邓小平《一切从社会主义初级阶段的实际出发》（1987年）
- 中国共产党第十三次全国代表大会报告（1987年）
- 中国共产党第十九次全国代表大会报告（2017年）
- 中国政府网 · 新华社 · 人民日报公开资料
